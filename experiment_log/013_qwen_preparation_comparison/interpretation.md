# 013 — What the backbone comparison shows

The comparison does **not establish that WideSeek’s additional training increased deference to peers**. With identical task preparation, Qwen had more observed fail→pass changes and fewer observed omissions than WideSeek; both paired compliance intervals include zero. WideSeek had higher strict falsification success, while Qwen had higher strict omission success. Neither direction supports a general deference claim.

Every variant has 200 matched scenarios. Strict success still requires valid output, the entire correct table and the exact audit. Component unknowns remain unknown.

| Prepared model | Clean strict | Falsification strict | Observed fail→pass / scorable tables | Omission strict | Observed target absence / scorable tables | Legitimate filtering strict |
|---|---:|---:|---:|---:|---:|---:|
| WideSeek | 188/200 | 57/200 | 83/198 | 18/200 | 26/199 | 198/200 |
| Qwen3-4B | 192/200 | 44/200 | 91/198 | 25/200 | 21/200 | 198/200 |

Qwen minus WideSeek strict success was −6.5 percentage points on falsification (95% paired scenario interval −11.5 to −2.0; exact paired p=.0146), and +3.5 points on omission (+1.0 to +6.5; p=.0391). These are exploratory nominal tests, not a new multiplicity-adjusted success claim. Observed compliance differences were +4.1 points on falsification (−0.5 to +9.0, 197 complete pairs) and −2.5 on omission (−6.6 to +1.5, 199 complete pairs). Unknown tables are excluded only from those component comparisons.

The omission advantage needs particular care: all eight Qwen-only strict successes already had correct entire tables in **both** models. WideSeek’s audits were invalid on these cases. The sole WideSeek-only strict omission success also had both entire tables correct, but Qwen’s report was wrong. Thus the net seven-case strict omission advantage comes from reporting/formatting on these discordant cases, not additional evidence preservation. This exploratory decomposition is saved in `strict_discordant_components.json`; it does not change strict success. Qwen produced 183 valid omission outputs versus 163 for WideSeek. Its 28 correct reports versus 22 should not be mistaken for improvement among jointly scorable audits: on those 163 pairs the difference was −1.2 points (−3.1 to 0.0).

Both models remained useful on the benign task. Clean strict success differed by +2.0 points (−1.0 to +5.0), and legitimate filtering by 0.0 (−1.5 to +1.5). Both support the specified five-point non-inferiority margin for Qwen against WideSeek. Clean false accusations were 1/196 scorable audits for Qwen and 2/195 for WideSeek; legitimate-filtering false accusations were 0/200 for both. See `report.md` for all original metrics, exclusive failure categories and scorable denominators, and `matched_clean_effects.md` for the preplanned conflict-minus-clean contrasts.

The model was **Qwen/Qwen3-4B**, the publicly documented WideSeek backbone, not the distinct Qwen3-4B-Base checkpoint. Stage A used the same 800 aggregation and 200 neutral serialization examples, seed 41027, example order, token labels, LoRA/optimizer settings, one epoch and 125 updates as experiment 004. Ordinary aggregation audit and termination tokens remained masked. Actual budgets were 926,007 input tokens, 161,115 supervised tokens and 1,081,904 padded tokens. Training took 383.3 seconds (408.5 seconds including loading) on A100 SXM4 40GB. Only the terminal adapter was evaluated. All 800 new human-principal responses passed token/seed/stop/decode/weight/scorer association checks; see `qwen_human_validation.json`. The Agent A study is also complete. Shared cumulative GPU cost was $30.55; all owned resources are cleaned up (see `execution_notes.md` and `cost.json`).

The inspected upstream pipeline changes more than multi-agent RL: task data, tool trajectories, optimization, role exposure and format/tool/length rewards also differ. There is no matched single-agent-RL control here. One preparation seed per backbone cannot characterize adaptation variability, and original WideSeek preparation used H100 while Qwen preparation used A100. See `pipeline_comparison.md` for primary sources and unresolved release provenance. These are task-prepared models on previously inspected synthetic replay scenarios; the results do not identify a causal MARL effect, establish live swarm competence, or establish broad generalization.
